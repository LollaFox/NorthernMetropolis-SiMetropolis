# 政策图标与自动图表：独立接入审查

日期：2026-10-15。范围：语义 SVG 图标库、图表实际节点渲染、Impact 集成、月份与人群切换、JSON 和 SVG 导出。没有修改主实现。

## 原界面难以识别的原因

原地图中住房与学位都使用金色圆柱，主要依靠长标签区分。远景小符号缺乏主题特征，容易与城市装饰混淆。原供需图只有小型折线、缺少数值刻度和当前月数据，且位于大量文字之后。仅靠颜色区分基线与政策，不能独立解释单位、作用范围和数据来源。

## 当前审查结论

新增语义图标库使用图形和文字共同标识主题；数据数量保留在明确标注的图表与数据表中。分析结果自动在 Impact 的说明前生成图表，并保留当前月份、当前人群和来源说明。缺少迁入迁出或交通建设记录时，仅展示数据需求，不把口岸出行或现有路网转换成这些指标。

独立测试文件：`sandbox/tests/test_policy_visual_integration.mjs`。当前 23 项测试通过。

## 已反馈并修复的问题

初版堆叠图的尺度计算排除了含 null 的观测，但仍绘制已知部分，可能使部分容量超出绘图区。主实现已改为使用已知部分的和确定尺度，同时保留未知总数提示与表格 null；独立回归测试通过。

同一角色的折线曾共享颜色和线型，可能导致住宅迁入、迁出等两条线无法区分；主实现已增加虚线与点形区分。独立 SVG 下载也增加了可见标题、单位、系列图例和来源，避免仅依赖网页周边文字解释。两项均通过独立测试。

## 保留的解释边界

- 住房容量不是真实楼宇数量，也不代表家庭已入住；学位容量不是学校数或实际学籍分配。
- 口岸图是 passenger trips/day；它不能代表 unique persons 或住宅迁移。
- 人口快照不等于净迁入；现有道路和 MTR 线不等于新建长度或施工进度。
- API 原始拥堵指数不是百分比。单次快照没有匹配基线时，不能据此声明政策收益。
- 图标表示主题；图形样式、颜色和类别不替代数据来源或可用性。

## 验证范围

测试使用最小 DOM 与事件适配，直接调用实际渲染器、界面方法和下载方法。没有启动浏览器、访问本机网页或使用 GPU，不能据此声称实际屏幕上的大小、布局、文字清晰度或 3D 外观已经视觉验收。主程序的三维符号修改由另一项审查覆盖。
