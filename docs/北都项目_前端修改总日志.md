## 5. G1：中文政府交互参考版

**目标：**探索“片区 → 政策预览 → 执行 → 观察 → 同月比较”的政府分析流程，并试接官方地理背景。  
**后续反馈：**用户认为变化过大，尤其不应把原英文产品改成全中文工作台。该版本保留为探索记录，不再作为当前界面演进基线。

| ID | 修改区域 | 已实现内容 | 边界／关联逻辑 |
| --- | --- | --- | --- |
| G01 | 整体页面 | 中文政府工作台，桌面三栏，窄屏先政策后地图 | 与原版布局差异较大；后续不沿用此重构方向 |
| G02 | 政策输入 | 片区选择、自由文本、住房/交通/绿化方向建议 | 建议只填入文本，不自动执行 |
| G03 | 政策预览 | 展示执行角色、成本、容量、建设周期及作用范围 | 预览不扣款，使用短期凭证 |
| G04 | 执行确认 | 确认后创建工程与记录 | 重新检查状态；重复或过期凭证不能重复扣款 |
| G05 | 支持边界 | 拒绝数量、复合动作、否定、区域冲突及不支持的附加条件 | 受控短语匹配；不是新接入的 LLM 理解能力 |
| G06 | 片区联动 | 建设施工选址限制在所选模型分区 | 模型分区不是官方开发区法定边界；共享财政等仍为全局状态 |
| G07 | 观察窗口 | 增加观察后续 12 个月的操作 | 观察后暂停；没有把模型时间当现实建设进度 |
| G08 | 历史与分支 | 历史只读，明确命名并创建另一方案后再干预 | 改变了原版从历史操作隐式分支的体验 |
| G09 | 方案比较 | 同一个已保存月份比较区域容量、全局财政与排放 | 比较只读；差异不是已识别的现实因果效应 |
| G10 | 地图 | 保留示意 3D；增加真实行政区地图切换 | 离线 18 区 GeoJSON，突出元朗区与北区 |
| G11 | 现实背景 | 展示 2021 年人口普查、机构、年份和链接 | 未把行政区总人口写入四片区模拟人口 |
| G12 | 结果口径 | 区分片区容量、全局指标、官方数据与假设 | 无真实建筑重建、迁移校准或实测通勤模型 |
| G13 | 执行与角色信息 | 展示建设状态、干预记录及规则角色消息 | 当前为规则模式；本轮未调用收费模型 |
| G14 | 默认状态和导出 | 独立存档、启动暂停、数据说明和导出 | 保留 A/B 两条演示方案，用于复查交互 |

**源码核对：**相对 B0，前端修改 `index.html`、`app.js`、`styles.css`；新增后端 `reference.py`，并修改 `engine.py`、`server.py` 支持参考流程。此版不能仅复制界面文件就获得全部功能。

**当时验证：**34 项原引擎测试与 16 项参考逻辑测试通过；检查预览不扣款、片区选址、建设投运、分支隔离、同月比较和官方地图显示。桌面 1280×900 及窄屏进行了视觉/操作检查。未完成经验预测精度验证。
