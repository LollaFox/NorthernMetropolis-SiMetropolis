# 左侧分析栏 UI 微调

版本：H3-round-2-left-ui-2026-10-17。本次是第二轮的展示细化，仍在原8893项目中修改。刷新http://127.0.0.1:8893/；如浏览器仍保留旧样式，可使用⌘⇧R强制刷新。

## 用户如何找到与操作

1. Start analysis完成或Analysis history打开已有结果后，在左侧看到SPATIAL VIEW入口，包含2D analysis与Change symbols。
2. 点击2D analysis，在同一左边缘展开分析栏，原入口暂时让位；右上×收起后恢复入口。
3. 使用图标＋文字专题按钮切换地图。后端有建设、居民、居民容量、岗位与站点；本地仍按皇岗、住房、学位的数据能力显示。
4. 继续使用底部Result month或保存城市的←/▶/→。左栏日期、图、数值与变化标记同步。
5. 点图中标记看具体数值。Data & comparison按需展开来源、比较和局限；Change symbols展开原8种符号。

## 这次改变了什么

- 左侧入口改为紧凑的纵向工具区，明确文字标签，不再使用一条悬浮横条。
- 展开栏与入口对齐同一左边缘，接近原界面的深色面板、细边框、金色选中态；地图保留浅色底，避免政策颜色被背景吞没。
- 专题由窄小缩略图列改为两列图标文字按钮，取消重复绘制的缩略地图，完整宽度用于主图。
- 面板按标题、当前月、专题、主图/图例、选中值、详细说明排布。来源与比较细节折叠，底部持续注明Schematic model，避免隐去数据性质。
- 面板宽度随窗口调整，内容内部滚动；矮屏仍可覆盖部分左下看板，关闭即可恢复。减少动画偏好下不播放出现动画。
- 保留顶栏Map appearance邻接Settings、启动Original material、Evidence与菜单互斥、Esc与焦点恢复。

原第二轮说明中的“浅色外面板、缩略图列”对应旧版。当前以本文为准：深色外栏＋浅色主图＋文字专题按钮。平面数据适配、单位、全期尺度与符号含义继续沿用第二轮。
