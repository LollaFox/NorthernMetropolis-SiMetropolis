# 前端已完成什么，后端接着做什么

版本：**H3-8893-visuals-2026-10-15**｜2026-10-15（香港时间）。

**当前页面**：http://127.0.0.1:8893/  
**当前代码**：`outputs/northern-metropolis-white-model`，网页入口为`sandbox/web/index.html`和`app.js`。不要接到旧8892或8894版本。

## 前端已完成

1. 片区、政策标签和具体政策选择，以及开始分析、按月份查看结果。
2. 原页面内的政策解读、自动图表、地图符号和JSON/SVG导出。
3. 本地皇岗、住房、学位演示；案例和政策修订记录相互隔离。
4. PDF上传→初始化审查→用户确认→模拟→按月取结果的API客户端与本机转发适配；异步等待、失败提示和旧响应隔离已实现。

**这里“完成”指前端与接口适配代码已实现，不代表真实后端已经联通。** 当前`backendConfigured=false`。API test是合成数据，不解析PDF、不调用LLM；住房和学位也是假设模型。

## 后端接着提供

- 初始化、审查确认、模拟创建、按月快照；耗时任务再提供job查询。
- 数据的来源、单位、日期、地区范围，以及哪些是事实、假设或缺失。
- 服务地址和字段确认；前端网关通过`V3_BACKEND_URL`连接。

## 尚未完成，不能当成已有能力

- 皇岗的Port opening / Transport capacity / Information reach仍是同一模型的三个关注点；各自独立干预与反事实对照待双方约定。
- 真实政策库、自动标签、LLM/Agent决策、居民迁移、交通施工进度及真实预测验证尚未接入。
- 当前路由与字段是前端可运行提案，需后端确认；最近398项检查是软件回归，不是现实效果证明。

**对接顺序**：先读[接口要求](01_接口对接要求.md)，再读[五个必读文件](02_必读文件清单.md)；先用合成响应跑通完整链路，再替换真实模型数据。源码和示例随交接包提供，不包含密钥或个人浏览器存档。
