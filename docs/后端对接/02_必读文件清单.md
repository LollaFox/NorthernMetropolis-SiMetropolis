# 给后端队友的阅读顺序

只需先读前五项；路径均相对当前项目根目录。完整源码会随交接包的`frontend/`提供。

| 顺序 | 文件 | 读它要确认什么 |
| --- | --- | --- |
| 1 | `docs/后端对接/00_前端完成说明.md`、`01_接口对接要求.md` | 已完成与未完成边界，最小路由、字段及联调流程 |
| 2 | `sandbox/web/v3-contract.js` | **返回字段和校验的实际依据**，尤其snapshotResponse |
| 3 | `sandbox/web/v3-api.js` | 实际请求、multipart、确认版本、任务轮询、幂等键和取月度快照 |
| 4 | `sandbox/web/v3-fixture.js` | 已能通过前端校验的合成响应生成方式；不是实际模型 |
| 5 | `sandbox/v3_gateway.py` | 后端地址配置、固定转发路由、令牌及工程容量限制 |

接政策与Agent时再读：

- `sandbox/web/policy-catalog.js`：地区/政策ID、模型和种子标签。
- `sandbox/web/analysis-compact.js`：主入口分流和实际发送的policyScope。
- `sandbox/web/policy-chart-model.js`：自动图表需要的数据、居住迁移与施工扩展模板。
- `sandbox/web/policy-interpretation.js`：解读口径，哪些结论不能凭现有字段推导。
- `docs/visual-library/*.template.json`：两类扩展空模板；尚未纳入团队V3契约。

运行与检验再读：

- `sandbox/server.py`：原本机服务与V3路由并存。
- `sandbox/tests/test_v3.mjs`、`test_v3_gateway.py`、`test_compact_http.py`：契约、转发和同源路由验收。
- `docs/政策可视化图标库与自动图表.md`：当前可视化能力与缺数据边界。

**不要先读**旧`sandbox_v1`、8894试验目录或历史备份。它们不在本次主源码包中。当前包不附浏览器案例、城市个人存档或密钥。
