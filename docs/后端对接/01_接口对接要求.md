# 后端最小对接要求

本页依据当前源码整理，是**待双方确认的提案**。如果后端已有不同路由或结构，可修改网关/适配器，不要求重做前端。

## 1. 调用关系

浏览器 → 本机`/api/v3/*` → `sandbox/v3_gateway.py` → `V3_BACKEND_URL`所指的团队后端。

下表写团队后端相对路径，浏览器端会加`/api/v3`前缀：

| 方法与路径 | 请求 | 返回 |
| --- | --- | --- |
| POST `/initializations` | multipart：`metadata`是JSON字符串，`plan`是PDF文件 | initializationId、reviewVersion、items |
| POST `/initializations/{id}/confirm` | JSON：reviewVersion | confirmed=true、同一reviewVersion |
| POST `/simulations` | JSON：initializationId、reviewVersion | simulationId、snapshots列表（id、date） |
| GET `/simulations/{id}/snapshots/{snapshotId}` | 无请求体 | 该日期的完整快照 |
| GET `/jobs/{jobId}` | 异步任务时使用 | queued/running，或complete+result，或failed+error |

`GET /api/v3/config`由本机网关提供，团队后端不必重复实现。旧`/api/state`等本机城市接口继续保留，不是上述研究模拟接口。

POST均携带`Idempotency-Key`；相同键重试应复用同一操作，避免重复任务。直接成功结果可同步返回；异步可返回`{"status":"queued","jobId":"job-1"}`，完成后`{"status":"complete","result":{...}}`的result须符合该阶段结构。前端取消等待不代表服务端任务已经取消。

## 2. 输入metadata

必需的现有研究设置：

- `bounds`：west/south/east/north，经纬度矩形；现版范围113.7–114.7°E、22.1–22.9°N。
- `start/end`：YYYY-MM-DD；start早于香港当天，end不早于start。
- `step`：month / quarter / year。
- 前端规范化后附`crs=EPSG:4326`及`vertices`。
- `policyScope`：schema、purpose、tags、policyId、areaId、model、catalogVersion。它是前端新增扩展，需后端确认和实现路由；标签并不等于后端已支持该政策。

研究片区ID与矩形坐标是两个输入，不能假设它们天然代表同一官方施策范围。当前三个种子政策和示意地区定义见`policy-catalog.js`；正式地理范围需双方确认。

PDF前端限制20MB，本机请求总量限制21MB；这两项是当前预览工程限制，非原Word给定规范。

## 3. 审查与结果

审查items中每项包含`id/field/kind/description`；kind为`sourced/assumption/unresolved`。前两类需value；sourced需可用sources链接。存在unresolved时前端阻止确认。请勿把模型编造的内容标为sourced。

模拟索引只返回实际可提供的快照，日期需按请求步长排列，id与日期不可重复；切月时前端再取完整快照，不用浏览器自行编造缺月。最多240个快照。

## 4. 快照结构：以v3-contract.js为准

| 字段 | 当前校验要求 |
| --- | --- |
| schema / date | `nm-v3-draft-1`，日期与所请求快照一致 |
| grid | width=height=1000；origin=north-west；order=row-major；heightUnit=m；crs=EPSG:4326；originLonLat=[西界,北界]；显式cellSizeM>0 |
| height | `{dtype:"float32",values:[...]}`，一维展开1,000,000项，有限数 |
| landType | int16一维1,000,000项，代码-1/0/1/2/3/4/5；业务含义仍需团队确认 |
| pollution | int16一维20,000项；按4×5000的行展开x/y/半径/type；整列全-1表示未用 |
| roads / mtr | points和congestion；road点3维、MTR点2维；每段一个拥堵值，缺失可null |
| zones | name/type、闭合boundary、population、jobs[type/count]、satisfaction（可null） |
| powerLines | 二维格网点组成的折线数组 |

坐标索引为0–999；快照外层roads/mtr/zones/powerLines数组必需，可为空。其余细项范围见`v3-contract.js`的`snapshotResponse`。JSON必须发送普通数组，不能直接把TypedArray序列化成数字键对象。

当前网关单次响应上限48MB，矢量点总量上限200,000。百万格网、原文最长边÷100矛盾、污染半径单位、类型码含义、满意度/拥堵量表等仍须确认；不能把现版预览提案当成后端已承诺实现。

API目前没有政策反事实基线、政策修订、Agent轨迹、住房/学位快照字段，所以API结果仅做返回值展示。若要复用本地专题效果或独立政策对照，需另约定带地区、日期、单位、来源和模型版本的输出；不能直接把本地假设数字拼成后端结果。

## 5. 接入启动

如果团队路由是`http://127.0.0.1:8000/initializations`，则V3_BACKEND_URL设为`http://127.0.0.1:8000`；如果团队路由包含`/api/v3/initializations`，则base设为`http://127.0.0.1:8000/api/v3`。网关会直接拼接上述相对路径。

从交接包的`frontend`目录运行：

```sh
V3_BACKEND_URL=http://127.0.0.1:8000 python3 -B sandbox/server.py --port 8893 --live-request-limit 0
```

已有8893服务时先由操作者停止原服务，或使用别的空闲端口。可选V3_BACKEND_TOKEN仅配置于服务端环境，不写进网页或交接文件。前端在 Configure 中选择脚本和年数，填写 DeepSeek 密钥，再走初始化→确认→模拟。不上传 PDF，也不读取密钥文件。第一次联调优先返回示例格式的合成响应，页面要保持 synthetic 标记。

## 6. 双方联调验收

1. 初始化能显示来源/假设/未解决项，未解决项阻止确认。
2. 重复POST不创建重复任务，错误明确返回，不偷偷替换为本地演示。
3. 模拟返回日期列表，按月快照通过校验并进入原地图/图表。
4. 切月、换政策时迟到响应不覆盖新结果，来源和单位始终可见。

“跑通接口”与“真实模型可用/政策预测准确”分别验收。当前版本已完成前端适配，真实团队服务尚未配置。
