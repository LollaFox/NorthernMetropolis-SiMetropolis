# 常显政策标签与标准结果解读：独立接入审查

日期：2026-10-15。对象：既有英文分析沙盒的底栏入口、结果说明与导出。审查只读取主实现，新增独立测试；没有修改主界面文件。

## 结论

`sandbox/tests/test_analysis_interpretation_entry.mjs` 的 19 项测试全部通过。当前接入没有发现阻断问题。政策标签保持在原底栏，五类标签均可见；片区不支持的标签保留显示并禁用，提示切换到具体片区。清空标签后不会自动补回默认标签，必须重新选择后才能分析。

结果解读在口岸、住房、教育与 API 中采用相同的六段结构：作用范围、基线对比、作用机制、生效时间、证据边界和后续核实事项。摘要与来源始终展示；默认展开对比、机制和时间，其余可展开，支持 Expand all / Collapse all。文字来自规则或返回字段，不是新的 LLM 推断。

## 保留的解释边界

- Housing / Public services 标签是筛选入口，不代表已有住房负担、医疗、照护等完整模型。
- 本地住房和教育结果来自显式假设。容量增加、缺口缩小不等于真实居民已入住或学生已获分配。
- 口岸的 trips/day 不等于人数、迁入量或社会收益。
- API 单次快照可以解释返回字段；没有相同条件的无政策基线时，无法据此判断政策导致的变化。
- Export 的说明固定于导出时的当前结果与已确认作用域，不依据用户尚未应用的标签草稿。
