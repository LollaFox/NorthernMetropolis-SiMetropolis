## 1. 政策选择入口

原来的标签下拉改为底栏**常显的五类复选按钮**。金色边框和 POLICY TAGS · SELECT 标题标明主要入口；选中标签为金色，并显示已选数量。

| 控件 | 当前行为 |
| --- | --- |
| Study area | 选择皇岗、古洞北或洪水桥；限定本区可用标签 |
| Policy tags | 原生 checkbox 支持键盘和多选；所有类别均可见；当前区不可用项禁用，悬停或读屏名称说明应切换哪个片区 |
| Matching policy | 列出同时符合片区和所有已选标签的具体政策 |
| Start analysis | 应用草稿或复用当前分析；空标签、空政策、跨区/专题不匹配时禁止启动 |
| Result month | 只读取结果；解读随所选快照更新 |

**不再自动补回被清空的标签**。全部取消后清除旧分析视图及未完成的 API 会话，开始、配置、月份和导出均禁用；重新选标签后恢复匹配政策。这样不会把“没有选范围”误当成“使用默认范围”。

## 2. 六段标准解读

Impact 顶部先显示当前月份的结论与来源类型，再按以下结构解读。比较、机制和时间默认展开；其余可单独展开，Expand all 可完整阅读。

| 固定字段 | 回答的问题 | 具体要求 |
| --- | --- | --- |
| scope | 分析哪个政策、片区和人群？ | 明确住房家庭/学生/客流的单位和适用范围 |
| comparison | 相比什么，发生多少变化？ | 同月基线、政策情景、差值；缺少对照时明确不能判定增益 |
| mechanism | 为什么出现这个结果？ | 实际投用量、需求变化、信息触达、启用暴露或容量约束；跟随模型状态 |
| timing | 本月哪个版本有效，下一节点是什么？ | 只使用当月有效版本；等待投用、分期、已完成和窗口末分别说明 |
| limits | 哪些是证据，哪些仍是假设？ | 明示本地规则/合成 API/返回快照，不将原始指数变成百分比 |
| next | 接下来应核实什么？ | 根据当前瓶颈提出核实任务，例如确认交付日期、需求口径或接驳容量 |

该解读由经过测试的**确定性模板**生成，不调用 LLM。它使数值更可解释，没有提高基础模型的预测准确率，也不能充当法律、财务或规划效益评估。

## 3. 解读如何随案例变化

| 情形 | 应看到的解读 |
| --- | --- |
| 古洞北，2026-08 | 尚未投用，新增容量为零；说明 2027-02 的假设投用节点 |
| 古洞北，2027-02 | 需求 12,240 户，新增交付 400 套，政策后缺口 840 户；解释分期与需求增长 |
| 古洞北，2027-07 | 交付 1,600 套，但缺口改善为 1,440 户；改善按基线缺口封顶，不等同新增量 |
| 洪水桥，2027-09 | 新增 900 学位，基线缺口为 730 人，因此改善 730 人；不承诺实际入学 |
| 皇岗，切换 commuters | 结论和对照使用 commuter trips/day；共同接驳容量另行标注 all passengers |
| 皇岗，等待启用或信息触达0 | 分别解释零暴露、零信息门槛，不泛称居民没有需求 |
| API 无对照基线 | 报告实际返回字段，并说明单一快照不能推出政策效果；不借用住房本地模型补数 |

查看旧月份不会引用未来修订的参数或版本。后续观察日期只是可查看节点，不把未来输出解释为本月事实。

## 4. 统一格式与导出

三种 builder 均返回以下结构，并复用同一个界面 renderer：

```json
{
  "schema": "nm-policy-interpretation-v1",
  "title": "Current policy and result month",
  "basis": "Explicit source/model type",
  "summary": "Current-month conclusion with units",
  "sections": [
    {"id": "scope", "title": "Scope title", "items": ["Specific explanation"]}
  ]
}
```

真实输出始终包含上表六节。Export 在原 JSON 中增加 `interpretation`，对应导出的政策、月份和客群。API 尚无当前快照时为 null，不生成虚假结论。导出仍不是可恢复的案例导入包。

[八个解读示例](validation/standardized-interpretation-examples.json)覆盖住房等待/投用/完成、学位投用、皇岗等待/容量受限、合成 API 与缺少指标的快照。原 [八个参数场景](validation/topic-validation-examples.json)继续保留完整月度结果；两组示例用途不同。
