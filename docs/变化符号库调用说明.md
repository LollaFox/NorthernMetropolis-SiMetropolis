# 变化符号库调用说明

适用版本：H3-round-2-map-analysis-2026-10-17。模块为sandbox/web/change-symbols.js，导出CHANGE_SYMBOL_VERSION = nm-change-symbols-v1。使用现有浏览器原生ES module，不需安装依赖。

## 单独插入一个符号

```js
import {createChangeSymbol} from './change-symbols.js';

const holder = document.getElementById('your-change-holder');
holder.append(createChangeSymbol('completed', {size: 20}));
// 邻接文字应提供日期、对象以及“相对哪个月”。
```

默认生成带role=img、aria-label与title的SVG。若旁边已经有完全相同的文字，可设decorative:true；未知key退回Not comparable。颜色和路径包含在SVG属性里，不依赖plan-analysis.css。

## 数值差值选择符号

```js
import {deltaSymbol, createChangeSymbol} from './change-symbols.js';

const comparable = Number.isFinite(current) && Number.isFinite(previous);
const delta = comparable ? current - previous : null;
holder.replaceChildren(createChangeSymbol(deltaSymbol(delta)));
```

deltaSymbol只接收差值，不读取业务数据；正数increase、负数decrease、0 unchanged、null/undefined/NaN/Infinity unavailable。业务方必须先保证单位、时间和对象一致。第一次保存没有上月，不能自动把此前值设为0；仅在明确有上一保存月且对象当时不存在时，才可按“新对象此前无存量”的规则计算。

## 注册表和Key

CHANGE_SYMBOLS是冻结的注册表，每项含label、meaning、color和paths。支持added / removed / started / completed / increase / decrease / unchanged / unavailable。扩展新类别时添加唯一Key和含义，补充数据启用条件，并更新可访问文字、符号预览与调用测试；不要仅凭情绪或颜色命名“成功政策”。

added与completed不是同义：新出现且已完工的对象若上月没有，标为added；已有对象变为complete才标为completed。箭头只表示数值增减，不承诺更好或更坏，不用于没有OD数据的迁移方向。图标也不提供置信度或政策批准状态。

政策类别图标继续使用policy-visuals.js的createPolicyIcon（如housing / population / rail / education）。建议“类别图标＋数值＋单位＋变化符号＋比较月份”组合。不要把居民容量写成住房套数，不把通关人次写成迁入居民。

## 平面图接入

plan-analysis-model.js提供backendPlan、portPlan、topicPlan，返回nm-plan-analysis-v1。plan-map.js提供renderPlanMap，plan-analysis.js负责原界面月份与左侧开关同步。后端适配依赖原backend-results.js的canonical导出校验，不能只复制plan-map.js就期待任意GIS格式可用。

新增后端专题需要：提供稳定对象ID、精确sourceDate、坐标体系、单位、缺值定义和跨月比较口径；先在纯数据适配器定义features、全期bounds/scaleMax，再接到同一月份事件。缺少真实空间分布时，保持片区汇总或Unavailable，不生成随机点、热力图、覆盖圈或米制比例尺。
