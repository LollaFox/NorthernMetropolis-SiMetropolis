## 1 如何体验

1. 刷新后，城市默认Original material。顶栏顺序是Analysis sandbox / Analysis history / Map appearance / Settings / Help；Map appearance紧邻Settings，可切White study model或重置相机。材质选择不持久化，重新载入仍默认原材质。
2. 从Analysis sandbox运行本地分析，或从Analysis history打开后端保存城市/已分析案例。结果底部看板继续使用。
3. 点击左侧2D analysis，打开浅色平面分析面板。左列专题缩略图可直接切换右侧大图，不另建一套月份。
4. 继续用底部Result month或保存城市的←/▶/→。平面图、日期、指标和变化符号随当前保存月更新；不提交新分析，不请求模型。
5. 点击平面图中的对象、片区容量标记或客流端点，可读其值、单位与比较说明。支持Tab和Enter/空格选择，Esc收起并返回入口焦点。
6. 左侧Change symbols直接展开同一面板的符号库。默认不把8项解释铺满主界面。

左侧平面与Evidence浮窗按需切换，避免多个说明窗口同时堆叠；Settings、Map appearance或Help打开时收起平面面板。回到输入沙盒时，平面入口和面板隐藏，保留政策标签与Start analysis作为主入口。Clear view也隐藏平面工具。

## 2 参考图如何落实

保留“同一底图、多个专题缩略图、点击查看、图例明确”的阅读方式。采用浅色模型平面、灰色对象底图、专题颜色、可展开符号解释；不复制参考图中的真实街道、建筑高度或POI密度，因为当前数据不支持。

| 数据来源 | 可点击专题 | 图形表达 | 口径 |
| --- | --- | --- | --- |
| 后端保存城市 | Construction / Residents / Housing capacity / Filled jobs / Stations | 保存网格上的对象方块、站点菱形、数量圆点与变化标记 | 构造、位置、数值来自同一run和sourceDate；全部是合成模型结果 |
| 皇岗本地模型 | Baseline trips / Added trips | 口岸到四个片区的示意连线 | 双向人次合计；两张图、所有月份和群体共用线宽尺度；不是OD实测或迁移方向 |
| 住房本地模型 | Commissioned supply / Unmet demand | 一个片区汇总容量标记 | 住宅单位与家庭需求分列；没有单栋楼坐标就不拆散成楼宇点 |
| 学位本地模型 | Commissioned supply / Unmet demand | 一个片区汇总容量标记 | 学位与学生需求分列；不生成学校位置或服务覆盖圈 |
| API契约测试/未知外部空间格式 | 明确提示无支持的空间平面 | 保留空状态与符号说明 | 不借用后端或其他案例的空间数据填补 |

后端圆点大小使用全保存期最大值；模型网格范围也在整个保存期固定。切月不单独放大变化，不把每月都重新归一化。站点只展示模型对象，不补造轨道；没有地理坐标就不放米制比例尺或地理北向。已有132个对象是开发组团，方块不是实际建筑轮廓。

住房、学位的虚线矩形只是示意托盘，不是法定边界或服务范围。相对上个保存月的增减不等于政策因果效益。新增对象、已有对象完工和居民数量增加属于不同符号，不相互替代。

## 3 变化符号库

独立模块sandbox/web/change-symbols.js，版本nm-change-symbols-v1。可直接导入，不需要额外图标包或联网。与原policy-visuals.js的15种政策类别图标分工：类别图标回答“什么主题”，变化符号回答“相对哪条记录发生什么变化”。

| Key | 标识 | 含义与启用条件 |
| --- | --- | --- |
| added | ＋ | 有上个保存月，当前对象存在、上月不存在 |
| removed | − | 当前对象消失、上月存在；只在状态层保留其旧位置提示 |
| started | 开工架形 | 已有对象从planned变成construction |
| completed | ✓ | 已有对象从未完工状态变成complete |
| increase | ↑ | 同口径数值差大于0 |
| decrease | ↓ | 同口径数值差小于0，不自动解释为变差 |
| unchanged | ＝ | 可比数值或状态相同 |
| unavailable | ？ | 缺值或没有可比上月；不当作0 |

首次保存月没有上月，不标成“所有对象本月新增”。数值0有独立小淡点，缺失使用虚线/问号。图标有文字含义和辅助技术名称，不能只凭颜色理解。状态层优先显示新增、移除、开工或完工的小标记；数值层标注增减。选中可读精确数值，底部看板仍负责全城汇总。

复用示例见[变化符号库调用说明](变化符号库调用说明.md)。绘制检查图位于validation/change-symbols-2026-10-17.png，可供队友核对视觉含义。
