# 按月预览已保存城市：交互与API说明

版本：H3-monthly-replay-2026-10-16。直接在原8893英文界面调整，保留原白模、分析面板和本地政策演示。

## 操作流程

**Start analysis → 初始化审阅与确认 → 后端完成 → 原3D城市首个保存月 → 左右箭头或播放键回放。**

如果已有结果，点击Saved city即可直接查看，不需要再次Start analysis。默认停在第1个保存月，不会自动播放。当前离线示例的第1月为2025-01-01，共21个月，终点2026-09-01。

| 入口 | 行为 |
| --- | --- |
| ← | 回退一个已保存月；在首月禁用 |
| → | 前进一个已保存月；在末月禁用 |
| ▶ / Ⅱ | 播放/暂停，每1.6秒前进一月，到末月自动停止 |
| 末月点击▶ | 回到首月后重新播放 |
| Result month | 直接跳到指定月，并暂停自动播放 |
| 1 / 21 | 当前保存月序号 / 保存月总数 |
| 结果面板Result date | 与底栏、地图保持同一日期 |
| Saved object details | 查看所选对象在该月的建设阶段、容量、入住和岗位 |

这里使用左右箭头按钮，不绑定鼠标左右键。退出回放、切本地演示或新分析时暂停回放。已有记录中的季度输出不限制回放月份：内部canonical monthlyStates仍按月读取。

## 首个模拟月的口径

API的monthlyStates第1条就是第1次结算（step=1），日期为setup.start。因此默认打开第1条，不无条件跳过第1条去显示start+1个月，也不根据系统今天凭空增加未来城市。

“未来第一个月”应理解为所选情景的第1个保存模拟月。只有后端确实保存了某月，前端才能回放该月。当前后端日期校验与已有存档范围保持不变。

## API核对

| 接口 | 用途 | 前端约束 |
| --- | --- | --- |
| GET `/api/state` | 当前保存方案、world、playing、timeline、branches | 验证run身份与sourceDate |
| POST `/api/switch`，`{id}` | 选择已有方案 | 随后选择该方案首月或明确指定月 |
| GET `/api/v3/simulations/{id}/export` | 完整canonical状态、每对象统计及保存日期 | 内存缓存并校验simulationId，不反复下载大导出 |
| POST `/api/seek`，`{month}` | 精确选择保存月，并暂停 | month来自timeline[i].month，不直接把数组索引当作月份；跨年可大于11 |
| POST `/api/control`，`{playing:true/false,speed:1}` | 播放/暂停保存状态 | 不提交初始化、模拟或模型请求 |

原页面的轮询读取state后，按sourceDate更新月份、图表、对象详情和按钮状态。手动导航只需要seek，不重新加载地形栅格，也不每月销毁重建整套分析面板。原全局变更队列用于抑制迟到轮询覆盖刚选的月份。

本次修复后端一个边界错误：对较早保存方案发出暂停指令时，follow_latest原本可能把选择切回最新方案。现在显式播放/暂停会保持所选run。

## 建筑动画

同一方案切月时，新出现的建筑从低处长到该保存月的目标高度，已有施工建筑向该月进度平滑过渡，时长0.65秒。该过渡即使回放已暂停也能完成；系统启用“减少动态效果”时直接显示保存状态。

指标和建设状态立即采用目标月的实际保存值。动画不修改canonical progress，不产生月份之间的新预测；视觉中间高度不表示额外的施工测量。回退时仍存在的建筑可平滑降低进度；在更早月份尚不存在的对象直接移除，避免幽灵对象影响选择或统计。

## 政府脚本能看到什么

政府JSON规定对象类型、网格位置、startMonth与completionMonth。逐月能看到规划、建设、完成的状态变化，入住人口及岗位按照后端保存结果同步。对象仍是示意开发组团，地图位置是示意投影，不是实测GIS。

可以检查脚本是否按预期时间交付、当月容量/入住/岗位是否对应；仅有这一段回放不能证明政策造成了真实社会收益。该版本没有匹配的无政策反事实，PDF正文仍不解读，前端政策标签不会改写政府脚本。当前运行模式offline，未启用DeepSeek付费调用。
